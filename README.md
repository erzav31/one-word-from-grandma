# One Word From Grandma

The single word Grandma would text about AI: **Clanker**. It is the warm, slightly baffled, old-fashioned word she reaches for when the noisy metal man in the corner starts talking back — unmistakably about a robot, funny on its own, and not the obvious pick everyone else sent.

## Run

```sh
node main.ts
```

This writes exactly one word to `/output/entry.txt`.
